Introduction

Education is a fundamental human right, yet millions of children remain excluded from learning opportunities worldwide. This interactive dashboard analyzes UNICEF’s latest indicators to reveal:

  • Where children are most likely to miss school
  • Who is being left behind

Where Are Children Missing School? Global Pre-Enrollment Gaps

In 2019, the global average out-of-school rate stood at ≈ 14%, but regional extremes tell a starker story:Chad (86.1 %), Niger (76.2 %), and Samoa (64.9 %) top the list of exclusion, while the United Kingdom (0.002 %), Sweden (0.07 %), and France (0.08 %) virtually eliminate pre-primary dropouts. As you press “Play” or drag the year slider, observe how some nations steadily close these gaps, even as others remain mired in high rates of exclusion—underscoring the urgent need for targeted education policies in hotspots like Sub-Saharan Africa and South Asia.

How Continental Populations Have Evolved (2014–2022)

From 2014 to 2022, Asia showed an average out-of-school rate of 37.1 %, despite a 1.5 % population decline, suggesting systemic barriers beyond demographic pressure. North America, with 4.6 % population growth, recorded an 8.9 % out-of-school rate, while South America, growing by 5.5 %, maintained a low 0.7 % rate. These contrasts highlight how population trends alone don’t dictate exclusion—policy strength and infrastructure matter more.

import polars as pl
import plotly.graph_objects as go
import pycountry_convert as pc

# Use the same blue palette
BLUE_PALETTE = ['#03045e', '#023e8a', '#0077b6', '#0096c7', '#00b4d8', 
                '#48cae4', '#90e0ef', '#ade8f4', '#caf0f8']

# Load metadata
meta = pl.read_csv("unicef_metadata.csv", schema_overrides={"Population, total": pl.Float64})

# Map ISO3 → Continent
def get_continent(iso3: str) -> str:
    try:
        a2 = pc.country_alpha3_to_country_alpha2(iso3)
        code = pc.country_alpha2_to_continent_code(a2)
        return {
            'AF': 'Africa', 'AS': 'Asia', 'EU': 'Europe',
            'NA': 'North America', 'SA': 'South America', 'OC': 'Oceania'
        }.get(code, 'Other')
    except:
        return 'Other'

# Add continent column
meta = meta.with_columns(
    pl.col("alpha_3_code")
      .map_elements(get_continent, return_dtype=pl.Utf8)
      .alias("continent")
)

# Filter for 2014–2022 and aggregate
agg = (
    meta.filter((pl.col("year") >= 2014) & (pl.col("year") <= 2022))
        .group_by(["year", "continent"])
        .agg(pl.sum("Population, total").alias("total_population"))
        .sort(["continent", "year"])
        .to_pandas()
)

# Create the figure
fig = go.Figure()
continents = agg["continent"].unique().tolist()

# Add bar traces
for i, cont in enumerate(continents):
    sub = agg[agg.continent == cont]
    fig.add_trace(go.Bar(
        x=sub.year,
        y=sub.total_population,
        name=cont,
        marker_color=BLUE_PALETTE[i % len(BLUE_PALETTE)],
        marker_line_color='#03045e',
        marker_line_width=1,
        opacity=0.8,
        visible=(cont == "Europe")  # Show Europe by default
    ))

# Create dropdown buttons
buttons = []
for i, cont in enumerate(continents):
    vis = [j == i for j in range(len(fig.data))]
    buttons.append(dict(label=cont,
                        method="update",
                        args=[{"visible": vis}]))

# Update layout
fig.update_layout(
    xaxis={
        'title': "Year",
        'tickmode': "linear",
        'dtick': 1,
        'showgrid': False,
        'linecolor': '#0077b6',
        'title_font': {'color': '#023e8a'},
        'tickfont': {'color': '#0077b6'}
    },
    yaxis={
        'title': "Total Population",
        'showgrid': False,
        'linecolor': '#0077b6',
        'title_font': {'color': '#023e8a'},
        'tickfont': {'color': '#0077b6'}
    },
    plot_bgcolor='rgba(0,0,0,0)',
    paper_bgcolor='rgba(0,0,0,0)',
    font={'color': '#03045e'},
    height=500,
    legend={
        'bgcolor': '#e2f7fd',
        'bordercolor': '#0077b6',
        'borderwidth': 1
    },
    barmode='group',
    hovermode='x unified',
    margin={'t': 80, 'l': 60, 'r': 30, 'b': 60},

        buttons=buttons,
        direction="down",
        x=0.5,

        yanchor="top",

GDP per Capita vs. Out-of-School Rates Over Time

Each bubble marks a country’s out‐of‐school rate for a given year, sized by its GDP per capita and colored on the same scale. The fitted regression line reveals a significant global decline of about 5.5 percentage points per year (R² ≈ 0.07, p < 0.001). However, the wide dispersion around that line shows that economic wealth alone can’t explain educational exclusion— some lower‐income countries outperform their peers, while a few wealthier nations still struggle.

import pandas as pd
import plotly.graph_objects as go
from scipy import stats
import numpy as np

# Color palette
BLUE_PALETTE = ['#03045e', '#023e8a', '#0077b6', '#0096c7', '#00b4d8',
                '#48cae4', '#90e0ef', '#ade8f4', '#caf0f8']

# Load data
df = pd.read_csv("unicef_indicator_1.csv")
metadata = pd.read_csv("unicef_metadata.csv")

# Calculate regression line
x = df['time_period']
y = df['obs_value']
slope, intercept, r_value, p_value, std_err = stats.linregress(x, y)
line = slope * x + intercept

# Confidence interval
y_err = y - line
ci = 1.96 * np.std(y_err) / np.sqrt(len(x))  # 95% CI

# GDP + Population stats
country_stats = metadata.groupby('country').agg({
    'GDP per capita (constant 2015 US$)': 'mean',
    'Population, total': 'mean'
}).reset_index()

# Merge and clean data
merged_df = pd.merge(df, country_stats, on='country', how='left')
merged_df = merged_df.dropna(subset=['GDP per capita (constant 2015 US$)', 'obs_value'])

# Normalize GDP values for marker size
gdp_values = merged_df['GDP per capita (constant 2015 US$)']
gdp_normalized = (gdp_values / gdp_values.max()) * 30 + 5  # Marker size scaling

# Create figure
fig = go.Figure()

# Add confidence interval band (moved to be on top of points)
fig.add_trace(go.Scatter(
    x=np.concatenate([x, x[::-1]]),
    y=np.concatenate([line - ci, (line + ci)[::-1]]),
    fill='toself',
    fillcolor='rgba(0,119,182,0.2)',
    line_color='rgba(255,255,255,0)',
    name='95% Confidence Interval',
    hoverinfo='skip'
))

# Add scatter points
fig.add_trace(go.Scatter(
    x=merged_df['time_period'],
    y=merged_df['obs_value'],

            title='GDP per capita (2015 US$)',
            title_font=dict(color=BLUE_PALETTE[0]),
            tickfont=dict(color=BLUE_PALETTE[0]),
            x=1.02  # Move colorbar slightly to the right
        )
    ),
    text=merged_df.apply(lambda row: f"{row['country']}<br>"
                                     f"Year: {row['time_period']}<br>"
                                     f"Rate: {row['obs_value']:.1f}%<br>"
                                     f"GDP: ${row['GDP per capita (constant 2015 US$)']:,.0f}",
                         axis=1),
    hoverinfo='text'
))

# Add regression line (on top of everything)
fig.add_trace(go.Scatter(
    x=x,
    y=line,
    mode='lines',
    name='Regression Line',
    line=dict(color=BLUE_PALETTE[0], width=3, dash='solid'),
    hoverinfo='none'
))

# Layout with transparent background and no grid lines
fig.update_layout(

    xaxis=dict(
        title='<b>Year</b>',

Who’s Left Behind? Boys and Girls Out-of-School Trends by Region

Tracking boys and girls from 2014 through 2022 reveals persistent disparities across regions. In some continents—like Africa and Asia—girls consistently face higher exclusion, often due to economic and cultural barriers. Other regions, such as Oceania, show minimal difference between sexes. Use the continent dropdown to explore how these gendered trends have converged or diverged over time, highlighting where targeted interventions are most needed to ensure equal access for all children.

import polars as pl
import plotly.graph_objects as go
import pycountry_convert as pc

# ─── 1. Loading of data 
df = pl.read_csv("unicef_indicator_1.csv")

# slecting Male & Female
df = df.filter(pl.col("sex").is_in(["Male", "Female"]))

#  ISO3 code   to Continent
def get_continent(iso3: str) -> str:
    try:
        a2 = pc.country_alpha3_to_country_alpha2(iso3)
        code = pc.country_alpha2_to_continent_code(a2)
        return {
            'AF':'Africa','AS':'Asia','EU':'Europe',
            'NA':'North America','SA':'South America','OC':'Oceania'
        }.get(code, 'Other')
    except:
        return 'Other'

df = df.with_columns(
    pl.col("alpha_3_code")
      .map_elements(get_continent, return_dtype=pl.Utf8)
      .alias("continent")
)

# ─── 2. Aggregate average rates by year
ts = (
    df.group_by(["time_period","sex","continent"])
      .agg(pl.mean("obs_value").alias("avg_rate"))
      .sort(["continent","time_period","sex"])
      .to_pandas()
)

# building figure with trace for male and female indication
fig = go.Figure()
continents = sorted(ts["continent"].unique())
sexes = ["Male","Female"]

europe_button_index = continents.index("Europe") + 1

for cont in continents:
    sub = ts[ts.continent == cont]
    for sex in sexes:
        d = sub[sub.sex == sex]
        # europe for first visibility
        is_visible = (cont == "Europe")
        fig.add_trace(go.Scatter(
            x=d.time_period,
            y=d.avg_rate,
            mode="lines+markers",
            name=f"{cont} – {sex}",
            legendgroup=sex,
            visible=is_visible
        ))

buttons = []

buttons.append(dict(
    label="All",
    method="update",
    args=[{"visible": [True]*len(fig.data)}]
))

for cont in continents:
    vis = [trace.name.startswith(cont) for trace in fig.data]
    buttons.append(dict(
        label=cont,
        method="update",
        args=[{"visible": vis}]
    ))

# ─── 5. Final layout tweaks ────────────────────────────────────
fig.update_layout(

    yaxis=dict(
        title="Avg Rate (%)",
        showgrid=False,  
        linecolor='#0077b6'  
    ),
    updatemenus=[dict(
        active=europe_button_index,
        buttons=buttons,
        direction="down",
        x=0.5,
        xanchor="center",
        y=1.02,
        yanchor="bottom"
    )],
    margin=dict(t=100, l=60, r=30, b=60),
    legend_title="Trace",
    plot_bgcolor='rgba(0,0,0,0)',  
    paper_bgcolor='rgba(0,0,0,0)'  
)

# lines thickness
fig.update_traces(line=dict(width=2))

fig.show()

Conclusion

Our analysis reveals that tackling global out-of-school rates requires a multifaceted approach:

  • Geographic Focus: Hotspots such as Sub-Saharan Africa and South Asia bear the highest preschool exclusion and must be prioritized.
  • Contextual Strategies: Population size alone does not drive exclusion—effective policies and robust infrastructure are the real levers.
  • Economic Insights: While rising GDP correlates with lower exclusion, outliers show that governance and targeted investment matter most.
  • Gender Equity: Persistent gaps in many regions call for gender-sensitive programs to ensure both boys and girls share equal learning opportunities.

By combining data-driven resource allocation with community-led solutions, we can turn these insights into action and move closer to the goal of education for all.
